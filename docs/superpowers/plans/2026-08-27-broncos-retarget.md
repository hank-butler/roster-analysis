# Broncos Retarget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retarget the roster-analysis project from SF 49ers / NFC West to Denver Broncos / AFC West, regenerate all data products, and rewrite positioning docs mapped to the Broncos Analytics Engineer posting.

**Architecture:** Mechanical retarget, not a refactor. The valuation model, evolution engine, portfolio optimizer, and SB template modules are team-agnostic and untouched. Changes concentrate in: scraper constants, pipeline team lists, one module rename (`nfc_west_comparison` → `afc_west_comparison`), agent system prompts/filters, dashboard display strings, and docs. Data products are regenerated by re-running the existing pipeline against new contract scrapes.

**Tech Stack:** Python 3.11 (conda env `nfl_analytics`), pandas, requests/BeautifulSoup, rapidfuzz, Streamlit, pytest. Run everything from project root with `conda run -n nfl_analytics`.

```python
    def build_afc_west(self) -> pd.DataFrame:
        """Build and save afc_west_rosters.csv.

        Returns:
            Merged DataFrame for DEN, KC, LAC, LV.
        """
        output_path = self.output_dir / "afc_west_rosters.csv"
        if output_path.exists():
            logger.info(f"[SKIP] {output_path} already exists")
            return pd.read_csv(output_path)
        perf = self.load_performance_data()
        contracts = self.load_contract_data(["DEN", "KC", "LAC", "LV"])
        merged = self.merge(perf, contracts)
        merged.to_csv(output_path, index=False)
        logger.info(f"Saved AFC West roster ({len(merged)} players) to {output_path}")
        return merged
```
